# Chips — Messaging App

An Android messaging app built with an emphasis on security — real-time text and image messaging with Google-based authentication.

## Features

- 💬 Live messaging — text & images
- 🔐 Google-based login system
- 🔍 User search
- 🛡️ Built with extra attention to security in the messaging flow

## Tech Stack

- **Client:** Java, Material UI
- **Backend:** Firebase Firestore, Firebase Auth
